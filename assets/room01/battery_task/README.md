# 电池抓取与三孔海绵工位

按 2026-09-16 的 12 张实景照片和用户尺寸建立。当前默认启动场景是 `room01_battery_task.usda`：两块黄海绵各承托一节动态电池，中央为三盲孔红海绵。模型参数集中在 `scene_spec.json`，尺寸与摆放来源逐项记录；完整检查见 [检查报告](../../../reports/room01_battery_task/README.md)。

## 打开和重建

在仓库根目录运行：

```bash
# 当前电池工位，保持机器人初始姿态并打开 GUI
bash scripts/open_room01_sim.sh

# 查看桌面正面；机器人可能遮挡部分视线，另有 ReviewBatteryTop 俯视相机
bash scripts/open_room01_sim.sh --view /World/ReviewBatteryTop

# 原来的方块工位
bash scripts/open_room01_sim.sh --legacy

# 修改 scene_spec.json 后重建（先关闭正在显示此场景的窗口）
.venv-usd/bin/python scripts/build_room01_battery_task.py

# 原生三路 RGB 截图
bash scripts/open_room01_sim.sh --capture --headless --output reports/room01_battery_task/preview

# PhysX 孔洞、物体落稳、相机检查以及总览/俯视/近景渲染
source scripts/isaac_env.sh
python scripts/validate_room01_battery_task.py --headless
```

GUI 和离屏验证共用 GPU，应依次运行。`--legacy` 必须放在启动脚本的第一个参数。原来的方块场景、UMI 回放场景和旧 Blender 工程仍在原路径；本次以独立 USD 层更新，没有重写这些历史资产。当前电池版以 USD 为模型来源，旧 Blender 副本不包含本次更新。

## 当前物理范围

电池是独立动态刚体，设有碰撞和 CCD。黄海绵和红海绵目前按静态刚体近似，红块固定方式参照照片中的胶带；未测海绵形变、刚度、质量、摩擦和插入力。电池质量 20 g 是仿真初值。

孔和电池具有相同名义直径，**没有人为扩大孔径**。真实插入依赖海绵的少量形变及接触摩擦；当前刚性几何验证不能代表真实插入行为。后续控制验证应补充海绵接触/顺应模型、孔距和底座到桌面的实测定位，再定义有效插入深度和松手后的稳定保持条件。

当前交付是可运行的场景、关节保持和三路相机预览，尚未完成机器人抓取并插入电池的控制演示。旧 `RoomTaskSim.step()` 的方块抬升奖励不适用电池任务，电池配置调用该奖励接口会明确报未实现；不会把抬起电池当成插入成功。直接控制、观测及物理推进接口保留供后续接入新任务控制器。

`source_photos.json` 记录 12 张原照片的哈希及本机归档路径。照片批量原件保存在忽略版本控制的 `data/room01_battery_20260916/`。

按用户要求，已移除机器人左手旁的白色包装盒及条码状装饰条纹，同时移除本体静态碰撞。它仅是背景道具，不承担电池任务、控制或识别功能。
