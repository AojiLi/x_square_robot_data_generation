# 完整房间建模与检查

[可编辑 Blender 工程](../../assets/room01/full_room_model/room01_full.blend) · [模型说明](../../assets/room01/full_room_model/README.md)

![房间总览](Overview_cutaway.png)

工程包含完整观察范围的建筑围合、三把办公椅、圆凳、两张桌子、大型设备箱、工具箱、纸箱堆和主要小物件。房间外包络约 4.77 × 4.10 m，层高约 2.66 m，保留原始米制坐标。

预览使用 Blender Cycles。总览隐藏入口、西墙和吊顶以显示内部，这些构件仍保存在工程中。其余机位显示完整围合房间。

## 同机位比较

左侧为原照片的竖向校正与中心裁剪，右侧为相同相机参数下的 Blender 渲染。所有比较单元保持 736 × 552 原始输出像素。它们用于核对摆放和结构，不能视为整体照片还原度已达标的证明。

## 已完成检查

- 模型结构、米制单位、必要构件和贴图依赖检查通过，16 张文件图片已打包。
- 十个源照片相机的参数转换误差小于 0.001 像素；这只验证投影计算转换，不代表物件几何或原始 Polycam 标定达到该精度。
- 总览及七个拍摄机位已实际渲染并人工查看。
- 背景原扫描仅作为隐藏参考；物件和主要建筑由独立几何构成。

未清楚拍摄的物件厚度、圆角与遮挡结构采用近似建模；预览照明未做实景光照标定。窗外使用照片背景。碰撞、机器人和控制逻辑不属于这次 Blender 建模交付。
