# 双腕默认起始视角修正

默认环境 `reset()`、保存的 USD、Blender 审查副本和采集第 0 帧使用同一侧立手掌起始姿态。参考为用户指定的 `20260824T091633.664930Z-pid2632484-1c6fc5df/requests/request_000001/`。普通启动无需 `--joint-pose`。

## 修正内容

- 实际默认关节姿态与参考姿态统一。旧默认姿态下，腕部画面中桌边倾斜约 89.75°；当前名义起始姿态下接近 0°。
- 修复两轴腕部嵌套壳体的内部凸包自碰撞。仅过滤左右各一对 `wrist_pitch_link` / `elbow_yaw_link`；这些壳体的外物碰撞、手与物体的接触以及其余自碰撞均保留。
- 抓取测试先用 1.5 秒完成右手从侧立到掌心向下的关节过渡，然后开始接近、闭合和抬升流程。夹持点根据此前成功保持时方块在真实模拟手坐标系中的位置重新匹配，避免依赖原来的碰撞挤压偏差。相机始终固定在腕部，记录实际运动。
- 回归检查读取实际配置、保存的 USD 和运行时 `reset()`，同时验证桌边方向、关节保持误差及静止速度。旧实现只检查单独的对照姿态，会漏掉默认姿态不一致的问题。

## 诊断依据

[修正前的检查](before_reset_verification.json)复现了默认姿态不一致与左右桌边竖直三个失败项。[凸包几何检查](assembly_convex_overlap.json)显示两个腕部内部凸包的交叠区域可容纳半径约 27 mm 的球。

[只排除腕部内部两对碰撞的诊断](wrist_assembly_diagnostic.json)保留其余碰撞，将保持姿态的最大关节误差降到约 0.00011 rad，最大关节速度降到约 0.000048 rad/s。改变控制增益或转子惯量未能解决原问题，因此正式修正没有调整这些控制参数。
